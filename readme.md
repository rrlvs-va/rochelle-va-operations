# Rochelle V. Silvestre | Independent VA + Operations

Official website and publishing repository for Rochelle V. Silvestre.

## Live site

- Main website: https://rrlvsva.wasmer.app/
- The Rochelle Edit: https://rrlvsva.wasmer.app/blog/
- Blog archive: https://rrlvsva.wasmer.app/blog/archive.html

## Structure

- `main` contains the public website and live blog content store.
- `backend-deploy` contains the Wasmer inquiry, admin authentication, and blog publishing backend.
- Blog publishing is managed through the protected admin rather than by editing public HTML manually.

Site and portfolio maintained independently.
