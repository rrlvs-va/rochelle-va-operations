# Blog CMS Preview

This folder is a visual prototype for a future native business blog / Insights section for Rochelle V. Silvestre | Independent VA + Operations.

## Purpose

Evaluate the public article design and the authoring experience before connecting a real CMS or changing the live site's navigation.

## Included

- `index.html` — public Insights landing-page preview
- `article.html` — responsive sample article
- `admin/index.html` — interactive author/editor mockup with local image preview

## Deliberately not connected

- Authentication
- GitHub write access
- Media uploads/storage
- Draft persistence
- Publishing/deletion
- Sitemap changes
- Main-site navigation
- Umami tracking

All preview pages include `noindex,nofollow` and are intentionally kept outside the production site structure while the concept is being evaluated.

## Naming note

The existing navigation link remains **Service Policies**, while the actual page title/heading remains **Service Guidelines**. This preview does not change that convention.
